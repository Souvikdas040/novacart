## 📖 Overview

NovaCart is a modern, responsive electronics e-commerce web application built with **Next.js**, **React**, and **TypeScript**. The application provides a seamless shopping experience with a clean user interface, product browsing, wishlist management, shopping cart functionality, and a streamlined checkout process.

The project focuses on modern UI/UX principles, responsive layouts, reusable components, and efficient state management using the React Context API.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/NovaCart.git
```

Go to project directory

```bash
cd NovaCart
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Build project

```bash
npm run build
```

Start production server

```bash
npm start
```
